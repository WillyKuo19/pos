# 小店 POS v1：安裝與設定說明

單台 iPad 用的內用 POS。透過店內網路（Star WebPRNT）讓 mC-Print3 印廚房單和收據。

## 資料夾裡的檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 主程式（全部功能都在這個檔） |
| `sw.js` | 讓 App 斷外網也能開啟 |
| `manifest.webmanifest`、`icon-*.png` | 讓 iPad 能「加入主畫面」，像 App 一樣全螢幕開啟 |

---

## 第一步：放上網路（GitHub Pages，免費）

iPad 要用 HTTPS 網址打開，才能裝成 App、離線使用。

1. 到 GitHub 建一個新的 repository，例如 `my-pos`。
2. 把這個資料夾裡的所有檔案上傳到 repository 的最上層。
3. 進入 repository 的 **Settings → Pages**，Source 選 `main` branch，按 Save。
4. 等一兩分鐘，就會得到一個網址，例如 `https://你的帳號.github.io/my-pos/`。

> 用 Claude Code 的話，直接說「把這個資料夾推到 GitHub 並開啟 GitHub Pages」就可以。

## 第二步：在 iPad 裝成 App

1. 用 iPad 的 **Safari** 打開上面的網址。
2. 點分享按鈕 → **加入主畫面**。
3. **之後一律從主畫面的圖示打開**。
   - 重要：直接在 Safari 裡用和從主畫面打開，是兩份不同的資料。
   - 而且 Safari 可能會清掉很久沒開的網站資料。

## 第三步：設定 mC-Print3

### 3-1 接網路、查 IP
1. 用網路線把出單機接到店裡的路由器。
2. 出單機關機，**按住進紙鍵再開機**，看到開始進紙就放開。
3. 出單機會印出兩張自我測試單，第二張**倒數第三行**就是 IP（例如 `192.168.1.50`）。
4. 建議到路由器設定裡，把這個 IP 綁定成固定 IP，不然重開機後可能會變。

### 3-2 開啟 HTTPS，讓 iPad 信任出單機
App 放在 HTTPS 網址上，iPad 的安全規則就只允許它用 HTTPS 連出單機。所以要：

1. 在出單機的設定網頁（Web Configuration，瀏覽器打開 `https://出單機IP`）開啟 WebPRNT 的 HTTPS 功能，讓出單機產生自己的憑證。
2. 把出單機的憑證裝進 iPad 並設為信任：
   - 下載並安裝憑證描述檔：**設定 → 一般 → VPN 與裝置管理**。
   - 開啟完整信任：**設定 → 一般 → 關於本機 → 憑證信任設定**，把這張憑證打開。

這部分的詳細畫面以 Star 官方手冊為準：
- mC-Print3 使用 WebPRNT：https://star-m.jp/products/s_print/mcprint3/manual/en/settings/settingsWebPRNT.htm
- WebPRNT 使用手冊（憑證設定）：https://star-m.jp/products/s_print/sdk/webprnt/manual/en/_sampleProgram.htm

### 3-3 在 App 裡測試
1. 打開 App → **後台 → 設定與備份**。
2. 填入出單機 IP，勾選「用 HTTPS 連線」。
3. 按 **測試列印**。
   - 中文印成亂碼：把「文字編碼」換成另一個選項再試。
   - 顯示「連不到出單機」：通常是 iPad 還沒信任憑證，或是 iPad 和出單機不在同一個網路。

> **沒填 IP 時是「預覽模式」**：每次出單都會在螢幕上顯示單據長相。沒有出單機也能先熟悉整個流程。

## 日常操作

- **點餐**：點桌子 → 點品項（有口味或加料的品項會跳出選擇）→ **送單**，印出廚房單。
  - 同一桌再加點，只會印新加的品項，單據上會標示【加點】。
- **退菜**：已送出的品項按「退菜」，會印一張【退菜】單給廚房。
- **換桌**：點餐畫面右上角。
- **排桌位**：後台 → 桌位圖。
  - 按住桌子拖曳來移動。
  - 點一下桌子後，拖曳右下角的綠色圓點就能縮放，也可以用右邊的滑桿微調。
  - 「全部縮小／全部放大」會一次調整這一區所有的桌子。
- **結帳**：可以打折（折金額或打 % off）。選現金或信用卡，現金會自動算找零，完成後印收據。
  - 有接錢櫃的話，現金結帳會自動開錢櫃。
- **報表**：看每天的營業額、現金和信用卡小計、品項銷量。可以補印收據、作廢訂單、列印日結單。
- **備份**：報表頁或設定頁按「匯出備份」，存到「檔案」或雲端。**建議每天日結時備份一次**。

## 目前的限制（v1）

- 資料只存在一台 iPad，多台 iPad 之間不會同步。
- 不開統一發票，只印收據。
- 信用卡只記錄付款方式，不串接刷卡機。
